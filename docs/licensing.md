# Licensing of the recompilation port

## Our sources

The port (`host/`), the launcher (`launcher/`, `r3.py`), the scripts (`scripts/`, `tools/`) and the patches in `patches/`
are **GPL-2.0-or-later** (`LICENSE-GPL-2.0.txt`). The patches apply to the MIT-licensed ps3recomp toolkit and stay under its
license where they touch its code (the file headers of each patch say where a patch came from); `host/main.cpp` grew out of
the toolkit's own runner and keeps that MIT notice (`licenses/ps3recomp.txt`) beside ours.

`host/unself.cpp` ports the APP path of RPCS3's `rpcs3/Crypto/unself.cpp`, and `host/self_app_keys.inc` is the APP key table
of RPCS3's `rpcs3/Crypto/key_vault.cpp` (both GPL-2.0-or-later), generated by `tools/gen_app_keys.py` from a pinned commit.
`host/crypto.{h,cpp}` come from the Soulcalibur II HD port (same author).

`rsx_tiling` (a patch) uses the address math of envytools' `tile_translate_addr` (MIT), not RPCS3's.

## What goes into the host binary

| Component | License |
|---|---|
| ps3recomp toolkit (runtime, scaffold, HLE libraries) | MIT |
| SDL2 (static) | zlib |
| glslang (static) | BSD-3-Clause, with MIT and Apache-2.0 parts |
| SPIRV-Tools (static) | Apache-2.0 |
| SPIRV-Headers | MIT-style (Khronos) |
| SPIRV-Cross (static) | Apache-2.0 |
| ATRAC3plus decoder (LGPL-2.1) | **not linked**: built with `PS3RECOMP_ATRAC_LGPL=OFF`, the game imports no cellAtrac |

Apache-2.0 is compatible with GPL-3.0 but not with GPL-2.0-only. Our code allows "or later", so the host binary as a whole
is distributed under **GPL-3.0-or-later** (`LICENSE`). Every component above allows that. A release ships the licenses and
notices of the table in `licenses/`.

## What must not be shared

The game module (`game.dylib`), the lift (`recompiled/`, `spu/`), the decrypted `EBOOT.elf`, the data directory's `disc/`
mirror and `gamedata/`, and the game's own files are derived from or are the user's copy of the game. They live in the data
directory or the user's own folder and are never part of a release or of this repository.

Nothing is downloaded at run time.
